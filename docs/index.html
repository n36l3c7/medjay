Medjay

IoC analysis tool that queries OSINT sources and presents readable, actionable results.

Overview Source Changelog
Status: pre-alpha. Medjay is under active development and nothing is released yet. This page describes the project's goals; installation and usage pages will appear with the first functional release.

What it does

Medjay takes one or many Indicators of Compromise — IPv4 and IPv6 addresses, domains, URLs, file hashes and email addresses — looks them up against OSINT sources through their public APIs, enriches them with passive data that costs no API quota, and shows one aggregated verdict per indicator together with the evidence from each source.

The same core powers a command-line interface for pipelines and a local web interface for interactive triage. It is built for analysts, incident responders and SOC teams who want to triage indicators quickly without burning through free-tier API quotas.

Design principles

  • One core, thin front-ends. Parsing, lookups, caching, aggregation, history and export live in a single package; the CLI and the web UI only present results.
  • Respect API quotas. Per-source rate limiting, a local cache with configurable TTL, daily budgets and an offline mode that answers from cache only.
  • Passive by default. Medjay reads what sources already know; it never submits indicators for active scanning unless explicitly asked.
  • Explainable verdicts. The aggregation rule is documented and every per-source verdict is visible next to the aggregate.
  • Plugins everywhere. Sources and export formats share the same plugin interface, so adding one is a small, self-contained change.

Install from source

git clone https://github.com/n36l3c7/medjay.git
cd medjay
python -m pip install .
medjay --version

Requires Python 3.11 or newer.
