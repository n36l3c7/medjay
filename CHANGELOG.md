## [Unreleased]

### Added

- Project scaffolding: `pyproject.toml` with `hatchling` build backend, `src/`
  layout, `medjay` console entry point with `--version`.
- Development tooling: `ruff` (lint and format), `mypy` in strict mode, `pytest`.
- Continuous integration on GitHub Actions: lint and type checks, test matrix on
  Python 3.11, 3.12 and 3.13 across Ubuntu and Windows.
- MIT licence, README, this changelog, and the documentation site skeleton under
  `docs/`.
